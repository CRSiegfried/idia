# How-to guides

- [Write a leaf](write-a-leaf.md): a leaf of your own, outside idia, over a wire API or a
  model run in your own process, wrapped in a `Dispatcher` and passing the conformance
  suite.
- [Add a provider to idia](add-a-provider-to-idia.md): moving a leaf into idia, with its
  registry entry, extra, spec section, recordings and checks.
